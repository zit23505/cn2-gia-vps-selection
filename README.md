## CN2 GIA 到底贵在哪，值不值这个钱

中国电信的骨干网有三层现实。最常用的是 AS4134（ChinaNet，也叫 163 网），便宜、容量大，代价是晚高峰拥堵，普通线路丢包率飙到 30% 是常见现象。往上是 CN2（AS4809），这一层又分两档：CN2 GT（Global Transit）在 2019 年之后也开始堵，性价比一路下滑；CN2 GIA（Global Internet Access）是电信的顶级产品，回国流量走 59.43 高速节点，独立链路、负载轻，晚高峰基本不丢包。

贵的根源在成本结构。按搬瓦工官方给出的口径，CN2 GIA 的 IP transit 价格可以到 **$120/Mbps**，一条 1Gbps 满带宽跑一个月，账单能到 $100,000 级别。这个量级的成本决定了它不可能便宜卖，也决定了它容量有限——遇到 DDoS 攻击，服务商通常只能 nullroute（把 IP 直接黑洞掉），因为扛不住。

所以 CN2 GIA 买到的是“晚高峰不塌”，而非“加速”。电信用户到洛杉矶的延迟通常稳定在 130ms~160ms，这个数字不会因为你多花钱变成 30ms；30ms 那一档要靠香港机房，价格是另一个故事。如果你的访客全在欧美、或者你只是挂一个静态博客，这层溢价换不来任何收益，普通线路就够。
